# ⛏️ Chanakya Committee — 18-Hour Hackathon

## 🌐 Official Event Website

The official website developed for the **Chanakya Committee 18-Hour Hackathon**, conducted on **23–24 October** at the college.

The website is designed as a central platform for participants and visitors to **learn about the hackathon, explore the event timeline, view important updates, and access registration** through Unstop.

The website follows a **Minecraft-inspired interactive design**, creating an engaging and distinctive experience while keeping the event information easily accessible.

### 📅 Event Details

* 🏛️ **Event:** Chanakya Committee 18-Hour Hackathon
* ⏱️ **Duration:** 18 Hours
* 📅 **Date:** 23–24 October
* 📍 **Venue:** College Campus
* 🎮 **Theme:** Minecraft
* 🌐 **Website:** https://chanakyacraft.vercel.app/

### 🧱 Website Features

* 📖 **About the Hackathon** — Information about the event and its purpose.
* ⏳ **Event Timeline** — Complete timeline and important stages of the hackathon.
* 📝 **Registration** — Participants can access the registration process through **Unstop**.
* 👥 **Committee Members** — Information about the members involved in organizing the event.
* 📢 **Updates** — Important announcements and event-related updates.
* 🤝 **Sponsors** — Information about the sponsors supporting the hackathon.
* 🏛️ **About the Committee** — Information about the Chanakya Committee and its initiatives.
* 🎮 **Minecraft Theme** — A themed interface designed to provide an engaging event experience.
* 🛠️ Tech Stack: React + Vite for the frontend, with Supabase for database and backend services.


### 👨‍💻 Role & Contribution

**Tech Head — Chanakya Committee**

Responsible for the **design, development, implementation, and deployment** of the official hackathon website.

The website was developed to provide participants with a single platform to access essential event information and proceed to the official registration platform.
